== Description ==

[Main Site](https://www.wpcargo.com/) | [Documentation](https://www.wpcargo.com/knowledgebase/) | [Showcase](https://www.wpcargo.com/features/) | [Premium Addons](https://www.wpcargo.com/purchase) | [Demo](https://www.wpcargo.com/demo-login/)

WPCargo Address Book Add-ons help you manage the shipper/receiver address book. Available shortcode [wpc-address-book].

Features: 
- Set default shipper or receiver. 
- Manage Address Book  in client account  and admin account 
- Import  Address Book  
- Auto fill  form in  using  the address book
